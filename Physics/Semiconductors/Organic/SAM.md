Self-Assembled Monolayer

Applications
 
- FET channel
 
- Chemisorption from dilute solution
	- Single layer forms on surface
- Surface properties changed
- SAM layer functionality determined by nature of SAM material
 ![Exported image](../../../img/OneNote/SAM%20image%20da1740265c2050c6.png)

Insulating Surfaces
 
- Dielectric surfaces
- Silanes
- Si-Cl3
	- Octyl-trichloro-silane
- Assemble on insulators like glass
- Silanes with alkyl chains make surfaces hydrophobic
 ![Exported image](../../../img/OneNote/SAM%20image%20a8f058a3fc0053f9.png)
 
Metal Surfaces
 
- Thiols
	- S-H groups
	- Sulphur group
- Easily assemble on Au, Ag, Cu etc
- Very selective assembly process
	- Not glass

Applications
 
# Semiconducting Layers

- Ring groups
- Use pi-conjugated oligomers or polymers
	- Pi-pi stacking direction should be along current flow axis
- Requires semiconductor to self-assemble in right orientation
 ![Exported image](../../../img/OneNote/SAM%20image%2068b77da9e1c45a3d.png)  

# Dielectric Layers

- Dielectric layer for organic transistors
	- Thin as possible
	- Pinhole-free
	- High dielectric constant
- Well-ordered, dense SAM
	- Thinnest possible high quality layer

# Metal Layers

- For efficient charge injection
	- Matching work functions
- Use other end from sulphur groups as active area for changing work function
	- Dipole
- Adds a potential that electrons must be pulled against to extract electrons
- Amount of change to work function
	- Individual dipole strength
	- Density of molecules
	- Angle of dipole axis

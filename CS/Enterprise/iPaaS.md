**Integration Platform as a Service**
- *"Focuses on enabling app, device and system integration"*
- Helps with SaaS sprawl
- Data access centralisation across multi-cloud and on-prem silos
- Features
	- Connectors and Adapters
	- Low/No code development
	- Data transformation & mapping
	- Workflow automation
	- Real-time & batch processing
	- Advanced data monitoring & analytics
- Use Cases
	- App-to-app integration
	- Data integration
	- MicroServices & containerised deployments
	- DevOps integration
	- B2B integration
	- Managed file transfer
	- AI & machine learning-driven deployments
	- User experience enhancement
- [*"iPaaS solutions can also facilitate B2B integration, IoT integration, cloud integration, event stream integration, managed file transfer, integration between various business platforms and other types of integration."*](https://www.ibm.com/think/topics/ipaas)

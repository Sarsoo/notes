UTXO  
Unspent Transaction Output
 
- Abstraction of e-money
- Chain of ownership
	- Of digital signatures
- Owner signs message transferring ownership to receiver
	- Receiver as public key
	- Transaction
 
- As a whole are a set in a blockchain
	- Transactions consume elements and create new one
		- As ownership changes
	- Represents all the coins in the system
 
- Output of a blockchain not yet spent
- Only unspent outputs able to be used in future transactions
	- Prevent double spend

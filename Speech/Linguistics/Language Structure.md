# Language Signals
- Mode
	- Vocal-auditory
	- Visual
	- Chemical
- Semantic
	- What message being carried
- Pragmatic purpose
	- Objective of the message
- Interchangeable nodes
	- Both send and receive
	- Language generation and understanding
	- Speaking and listening
- Arbitrary form
	- Signal not logically related to signal's meaning
	- Iconic Systems
		- Woof
	- Onomatopoeia
- Discrete infinity
	- Single complex message can be created from smaller signal components
- Displacement
	- Discuss things not present in space or time
- Productivity
	- Generate and understand novel messages
	- Human communication is open system

Autonomous Barges

- Remote monitoring with ability to take over
- Harder for inland navigation
	- Narrow waterways
	- Locks
	- Under bridges
	- Near urban areas
	- 3 Challenges
		- Sub-meter accuracy in the presence of extreme multipath
			- Multi-path errors caused by GPS signals being reflected off structures
				- Lock walls, bridges, buildings
				- RTK Corrections
			- Interference
				- Worse inland than open-sea
			- Reliable heading information needed for vessel control
				- Can differ because of water currents and wind

Deep Learning In Autonomous Ship Nav
 
- Collision Avoidance
	- Most collisions caused by human error
	- International Maritime Organization 1972
		- Legal framework for ship encounters
		- Can be integrated into AI for collision recognition
- Anomaly Detection
	- Combine AIS with other sources
	- Deviation from standard route
	- Unexpected AIS activity
	- Unexpected port arrival
	- Close approach
	- Zone entry
- Path Planning
	- Deterministic
		- Rigorously defined steps in order to determine solution
	- Heuristic
		- Search in subspace of the search space for an 'acceptable' solution
	- Safety domain around each obstacle
		- Recent deep learning path planning
- Ship Classification
	- Object recognition and classification algorithms for imagery
	- Automatic Target Recognition (ATR)
	- Maritime Domain Awareness (MDA)
